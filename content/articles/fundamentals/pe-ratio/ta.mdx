PE விகிதம் (Price-to-Earnings Ratio) என்பது பங்கு பகுப்பாய்வில் பயன்படுத்தப்படும் மிகவும் பொதுவான மற்றும் முக்கியமான அளவீடுகளில் ஒன்று. இது ஒரு நிறுவனத்தின் பங்கு விலையை அதன் பங்கு당 வருமானத்தைக் (Earnings Per Share - EPS) கொண்டு வகுத்து கணக்கிடப்படுகிறது.

## PE விகிதம் எப்படி கணக்கிடப்படும்?

**தொகுப்பு:** பங்கு விலை / பங்கு당 வருமானம் (EPS)

எடுத்துக்காட்டாக, ஒரு நிறுவனத்தின் பங்கு விலை ₹500 மற்றும் அதன் EPS ₹25 ஆக இருந்தால், PE விகிதம் = 500 / 25 = 20 ஆகும். இது பொருளாக, முதலீட்டாளர்கள் இப்போது ₹1 வருமானத்திற்கு ₹20 செலவிட தயாராக இருக்கிறார்கள்.

## PE விகிதத்தின் வகைகள்

### 1. Trailing PE (தொடர் PE)
தொடர் 12 மாதங்களின் வைதிய வருவாய் மாற்று வைதிய விகிதம். இது பிறந்த நிலையான தரவில் அடிப்படையாகக் கொடுக்கப்பட்டுள்ளது.

### 2. Forward PE (முன் PE)
அடுத்த 12 மாதங்களுக்கான அனுமான வருமானம் அடிப்படையில் கணக்கிடப்படுகிறது. இது வைதியங்களின் எதிர்கால வளர்ச்சியை வைத்தியக்கிறது.

## PE விகிதம் எப்படி értel்க்க வேண்டும்?

- **குறைந்த PE (< 15):** பங்கு மதிப்பை விட குறைவாக விலைப்படுத்தப்பட்டிருக்கலாம் (undervalued) அல்லது நிறுவனம் சவால்களை எதிர்கொள்ளிறது.
- **நடுத்தர PE (15-25):** பங்கு நியாயமான மதிப்பில் விலைப்படுத்தப்பட்டிருக்கலாம்.
- **உயர் PE (> 25):** பங்கு அதிகம் விலைப்படுத்தப்பட்டிருக்கலாம் (overvalued) அல்லது அதிக வளர்ச்சி எதிர்பார்க்கப்படுகிறது.

> **முக்கியம்:** PE விகிதத்தை மட்டும் வைத்து முதலீட்டு முடிவெடுக்க வேண்டாம். இது ஒன்றில் மட்டும்ultur வைதியம்.

## ஏதேன் பிரச்சினைகளைப் பொறுத்துக்கொள்ளுங்கள்

1. **தொழில் வித்தியாசம்:** வைதியத் துறைகளுக்கு (IT, FMCG) உயர் PE இயல்பாக இருக்கிறது, ஆனால் வங்கி/ஆரோக்கியத் துறைகள் குறைந்த PE கொண்டிருக்கலாம்.
2. **வளர்ச்சி விகிதம்:** உயர் வளர்ச்சி நிறுவனங்கள் உயர் PE வைதியத்தக்கவை.
3. **பொருளாதார சுழற்சி:** 경기 மந்திய காலங்களில் PE விகிதம் மாறுபடலாம்.

## நிரூபிக்கப்பட்ட பயன்பாடு

```javascript
// எளிய PE கணக்கீடு
function calculatePE(price, eps) {
  if (eps <= 0) return null; // നேகேட்டிவ் EPS க்கு PE பொருளற்றது
  return price / eps;
}

console.log(calculatePE(500, 25)); // 20
```

## சுருக்கம்

PE விகிதம் ஒரு பயனுள்ள தொடக்கوقد் கருவி, ஆனால் இது முழு கதையை சொல்லவில்லை. எப்போதும் வேறு அளவீடுகள் (PB, ROE, Debt/Equity, Dividend Yield) மற்றும் துறை விலங்கு பகுப்பாய்வுடன் சேர்த்து பயன்படுத்தவும்.
